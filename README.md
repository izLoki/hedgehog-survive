# Headgehog Survive

Game made for the PostHog Cordoba convention
- Event #2

Topic: Agentic engineering with webgames

# About

Small game inspired by Binding of Isaac / Soul Knight, a roguelike designed for quick, simple, and addictive runs. Developed in ~2 hours using OpenCode with the oh-my-openagent plugin (GPT-5.5 and Kimi K2.6).
Pending future implementations: leaderboards, improved difficulty and progression, bosses, general HUD improvements, and broader in-game events.
